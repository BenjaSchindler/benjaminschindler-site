\section*{Proyectos para clientes}
\textbf{MiAutoCheck}: Tasación de vehículos usados. Un agente de visión evalúa las fotos, cinco agentes investigan el mercado en paralelo y un supervisor genera el informe PDF. Una tasación de 30--60 minutos pasó a ser una llamada de API de 3 minutos; cerca del 90\,\% de los informes se aprobó sin cambios importantes en un conjunto de validación.

\textbf{EPE}: Funciones de IA para bienestar laboral, con detección de crisis y ocultamiento de datos personales. Prompts versionados con pruebas A/B, LLM-as-judge con monitoreo de drift y Langfuse.
